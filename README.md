# 🚚 Meesho Shipping Price Optimizer

A smart logistics optimization platform that predicts and optimizes shipping prices based on package weight, delivery zone, distance, and courier rates.

---

## ✨ Features

- 📦 Shipping cost prediction
- ⚡ Courier price comparison
- 📍 Zone-based optimization
- 📊 Shipment analytics
- 🧠 Smart delivery recommendations

---

## 🛠 Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Python (Optional ML Integration)

---


## ⚙️ Installation

```bash
git clone https://github.com/your-username/meesho-shipping-price-optimizer.git

cd meesho-shipping-price-optimizer

# Backend
cd server
npm install
npm run dev

# Frontend
cd ../client
npm install
npm start
